# 🏢 우리 AI 사무실 — 쓰레드 자동 게시 키트

컴퓨터를 꺼놔도 내 쓰레드가 알아서 돌아가요.
코딩 몰라도 브라우저만 있으면 설치할 수 있어요. → **[설치 안내서](GUIDE.md)**

## 들어 있는 직원

| 직원 | 하는 일 | 언제 |
|---|---|---|
| 🐱 게시 담당 | 예약해둔 글·사진·영상 올리기 (이어 쓰기까지) | 15분마다 |
| 🐰 댓글 담당 | 정해둔 단어가 들어간 댓글에 답글 | 15분마다 |
| 🐹 통계 담당 | 팔로워 수가 바뀔 때마다 기록 | 15분마다 |
| 🐢 열쇠 담당 | 쓰레드 토큰 자동 연장 | 매달 1일·15일 |
| 🏢 AI 사무실 | 위 직원들이 실제로 일하는 모습을 귀여운 사무실로 | 항상 |

## 폴더

```
posts/queue/   올릴 글 (파일 이름 = 올릴 날짜와 시간)
posts/done/    올라간 글이 옮겨지는 곳
images/        글에 넣을 사진·영상
replies.json   댓글 자동 답장 규칙
docs/office/   AI 사무실 페이지
stats/         팔로워·답장 기록
```

## 꼭 지킬 것

- 토큰·비밀번호는 **절대 파일에 쓰지 말고** GitHub 비밀값(Secrets)에만
- 비밀번호를 바꾸면 토큰이 무효가 돼요 → 안내서 1단계 7번 다시
