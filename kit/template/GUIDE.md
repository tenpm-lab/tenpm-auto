# 🏢 나만의 AI 사무실 만들기

> 📸 표시는 화면 캡처가 들어갈 자리예요. (베타 전에 채움)

코딩 몰라도 돼요. 브라우저만 있으면 돼요.
순서는 이래요.

1. **사무실 띄우기** (10분) → 귀여운 사무실이 내 주소에 생겨요
2. **직원 꾸미기** (10분) → 이름·대사·동물을 AI한테 말로 바꿔요
3. **직원에게 진짜 일 시키기** (30분) → 쓰레드를 연결하면 직원들이 실제로 일해요
4. **나만의 직원 뽑기** (선택) → 원하는 일을 하는 직원을 AI한테 추가해달라고 해요

1~2단계만 해도 사무실은 완성이에요.
3단계부터는 "보여주기용"이 아니라 진짜로 일하는 사무실이 돼요.

---

## 1단계. 사무실 띄우기 (10분)

필요한 것: GitHub 계정 (무료, github.com에서 가입)

1. GitHub 오른쪽 위 **+ → New repository**
   - 이름: 아무거나 (예: `my-office`)
   - **Public** 선택 ← 꼭!
   - Create repository
   📸 저장소 만들기 화면
2. **Add file → Upload files**
   → 키트 압축을 푼 폴더 안의 파일·폴더를 **전부** 끌어다 놓기 → **Commit changes**
   ⚠️ 복사·붙여넣기 말고 **파일 올리기**로 해요. 붙여넣다가 내용이 빠진 적이 있었어요
   ⚠️ `.github` 폴더는 숨김 폴더라 안 보일 수 있어요 📸 숨김 폴더 보이게 하는 법
3. **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/docs** → Save
   📸 Pages 설정 화면
4. 1~2분 기다렸다가 이 주소로 들어가요
   `https://내아이디.github.io/저장소이름/office/`

직원 4명이 돌아다니는 사무실이 보이면 성공 🎉
직원을 눌러보고, 벽시계도 눌러보세요. (회식해요)

> 지금은 아직 일이 없어서 다들 놀고 있어요. 3단계에서 일을 줄 거예요.

---

## 2단계. 직원 꾸미기 (10분)

코드를 직접 고칠 필요 없어요. **AI한테 파일을 주고 말로 시키면 돼요.**
ChatGPT, Claude, 제미나이 뭐든 돼요.

### 하는 법

1. 저장소에서 `docs/office/chars.js` 파일을 열어요
2. 오른쪽 위 **복사 버튼**(📋)으로 내용을 통째로 복사해요
3. AI 채팅창에 붙여넣고, 아래 문장 중 하나를 같이 보내요
4. AI가 준 새 내용을 복사 → GitHub에서 그 파일 **연필(✏️) 버튼** → 전부 지우고 붙여넣기 → **Commit changes**
5. 1분 뒤 사무실 새로고침

📸 파일 복사 버튼 / 연필 버튼 위치

### 복붙용 문장

**대사 바꾸기**
```
이 파일에서 토끼(reply) 직원 대사를 내 말투로 바꿔줘.
"댓글 왔다!!", "사장님 댓글 3개요!", "답장은 제가 할게요" 이런 느낌으로.
파일 전체를 다시 보여줘.
```

**동물 바꾸기**
```
이 파일에서 고양이(poster) 직원을 강아지로 바꾸고, 셔츠 색은 민트색으로 해줘.
파일에 있는 동물 중에서만 골라줘. 파일 전체를 다시 보여줘.
```

**직급·성격 바꾸기**
```
직원 4명(poster, reply, stats, key)에게 회사원 직급이랑 성격을 정해줘.
예: 고양이 대리는 완벽주의, 토끼 사원은 수다쟁이.
성격에 맞게 대사도 3개씩 바꿔서 파일 전체를 다시 보여줘.
```

> 💡 직원 이름표(게시 담당, 댓글 담당…)는 `office/status.py` 안에 있어요. 같은 방법으로
> "status.py에서 직원 이름을 '냥대리', '토끼사원'으로 바꿔줘"라고 시키면 돼요.

---

## 3단계. 직원에게 진짜 일 시키기 (30분)

이제 직원들이 진짜로 일해요.

| 직원 | 하는 일 | 언제 |
|---|---|---|
| 🐱 게시 담당 | 예약해둔 글·사진·영상을 쓰레드에 올려요 | 15분마다 |
| 🐰 댓글 담당 | 정해둔 단어가 들어간 댓글에 답글을 달아요 | 15분마다 |
| 🐹 통계 담당 | 팔로워 수가 바뀔 때마다 기록해요 | 15분마다 |
| 🐢 열쇠 담당 | 쓰레드 열쇠(토큰)를 새로 바꿔요 | 매달 1일·15일 |

글이 올라가는 동안엔 직원이 자리에 앉아 일하고,
끝나면 탕비실에서 커피 마시고,
문제가 생기면 울상이 돼요.
**전부 실제 기록 그대로예요.**

필요한 것: 쓰레드 계정, 페이스북 계정 (개발자 등록용, 쓰레드 계정과 달라도 돼요), PC

### 3-1. 쓰레드 열쇠(토큰) 받기

토큰은 "이 프로그램이 내 쓰레드에 글을 올려도 된다"는 열쇠예요.
🔒 **토큰은 아무 데도 붙여넣지 마세요. 채팅창·메모장·파일 전부 안 돼요. GitHub 비밀값 칸에만 넣어요.**

1. **developers.facebook.com** → 개발자 등록
   브라우저에 로그인된 페이스북 계정으로 해도 돼요. 앱 주인일 뿐, 글이 올라가는 계정과는 상관없어요.
   📸
2. **앱 만들기**
   - 이용 사례: **"Threads API 액세스"** 하나만 체크
   - 비즈니스 연결: **안 함**
   - 앱 이름: 아무거나 (예: my-office)
   📸
3. **이용 사례 → 권한 및 기능** → 아래를 추가
   - threads_content_publish (글 올리기)
   - threads_manage_replies (답글 달기)
   - threads_read_replies (댓글 읽기)
   - threads_manage_insights (팔로워 수 보기)
   📸
4. **이용 사례 → 설정** → 콜백 URL 칸 3개에 내 블로그나 아무 내 사이트 주소 → 저장
   ⚠️ "OAuth 리디렉션 URI를 지정해주세요" 오류가 나면 → 주소를 다시 쓰고 **엔터**로 등록한 다음 저장
   📸
5. **앱 역할 → "Threads 테스터"** 탭 → 사람 추가 → 내 쓰레드 아이디 → "대기 중"이 보이면 OK
   ⚠️ 그냥 "테스터" 탭 말고 **"Threads 테스터"** 탭이에요
   📸
6. 폰 쓰레드 앱 → **설정 → 계정 → 웹사이트 권한 → 초대** → 수락
   ⚠️ 수락하면 버튼이 "삭제"로 바뀌어요. 정상이에요! 다시 보내지 마세요
   ⚠️ 수락하고 나면 메타 화면에서 내 아이디가 사라져요. 이것도 정상이에요
   📸
7. **이용 사례 → 설정** 맨 아래 **사용자 토큰 생성기** → 내 아이디 옆 "토큰 생성" → "계속"
   → 나온 긴 글자가 토큰이에요. **바로 다음 단계로!**
   📸 (토큰 글자는 가림)

### 3-2. 열쇠를 사무실 금고에 넣기

1. 내 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
2. Name: `THREADS_TOKEN` / Secret: 방금 받은 토큰 → Add secret
📸

### 3-3. 첫 글 올려보기

1. 저장소 `posts/queue` 폴더 → 예시 파일 열기 → 연필(✏️) 버튼
2. 내용을 내 글로 바꿔요
3. **파일 이름이 올라갈 시간**이에요. 지금보다 5분 전 시간으로 바꿔요
   예: 12월 1일 저녁 8시 30분 → `20261201-2030_첫글.txt`
4. Commit changes
5. **Actions → 예약 게시 → Run workflow**
   📸
6. 쓰레드에 글이 올라오고, 사무실에서 고양이가 자리에 앉아 일하면 성공 🎉

### 글 파일 쓰는 법

```
사진: a.jpg, b.mp4
주제: 일상
여기부터 본문이에요.
---
--- 위 줄 아래는 이어 쓰기(내 글에 다는 댓글)로 올라가요.
```

- `사진:` 줄은 선택이에요. 사진·영상은 `images` 폴더에 올려요. 2장 이상이면 넘겨보기 글이 돼요
- `주제:` 줄도 선택이에요. 쓰레드 주제 태그예요
- 폰 사진은 위치 정보를 지운 복사본을 올려요 (PC: 사진 오른쪽 클릭 → 속성 → 자세히 → 속성 및 개인 정보 제거)

### 3-4. 댓글 답장 규칙 정하기 (선택)

`replies.json`을 열어서 "단어"와 "답글"을 바꿔요.
댓글에 그 단어가 있으면 답글 중 하나를 골라 달아요.
한 번에 최대 5개, 같은 댓글엔 한 번만 달아서 스팸처럼 안 보여요.

### 3-5. 열쇠 자동 교체 (추천)

토큰은 60일이 지나면 만료돼요. 이걸 해두면 거북이 고문이 알아서 바꿔요.

1. GitHub 내 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access: 이 저장소만
   - Permissions → **Secrets: Read and write**
   📸
2. 나온 값을 3-2처럼 저장. 이름은 `GH_SECRETS_PAT`
3. **Actions → 토큰 연장 → Run workflow** 로 한 번 시험

⚠️ 쓰레드·인스타 **비밀번호를 바꾸면 토큰이 무효**가 돼요. 그땐 3-1의 7번만 다시 해서 `THREADS_TOKEN`을 바꿔요.

### 3-6. 폰 알림 (선택)

1. 폰에 **ntfy** 앱 설치 → 구독 → 남들이 못 맞힐 이름 (예: myoffice-x7k2q9)
2. 그 이름을 비밀값 `NTFY_TOPIC`으로 저장
3. **Actions → 예약 게시 → Run workflow** → mode 칸에 `알림테스트` → 폰에 알림 오면 성공

## 4단계. 나만의 직원 뽑기 (선택)

사무실의 진짜 재미는 여기예요. **원하는 일을 하는 직원을 AI한테 뽑아달라고 하면 돼요.**

1. 저장소에서 `office/status.py`, `docs/office/chars.js`, `.github/workflows/post.yml` 세 파일을 복사
2. AI 채팅창에 붙여넣고 이렇게 말해요

```
이건 내 AI 사무실 파일이야. 새 직원을 한 명 뽑고 싶어.
- 하는 일: (예: 매일 아침 9시에 날씨를 확인해서 비 오면 쓰레드에 "우산 챙기세요" 글 올리기)
- 동물: (예: 펭귄)
- 직급: (예: 인턴)
필요한 파일을 새로 만들거나 고쳐서 전부 보여줘.
GitHub에 어떤 파일을 어디에 올리면 되는지도 순서대로 알려줘.
토큰 같은 비밀값은 파일에 쓰지 말고 GitHub Secrets에서 읽게 해줘.
```

3. AI가 알려주는 대로 파일을 올리면 새 직원이 출근해요 🐧

> 💡 막히면 Actions의 빨간 X를 눌러서 나온 오류 문장을 그대로 AI한테 보여주면 대부분 해결돼요.

## 자주 막히는 곳

| 증상 | 이렇게 해요 |
|---|---|
| 사무실 주소가 404 | Pages 설정 후 1~2분 기다리기. 폴더가 `/docs`인지 확인 |
| 사무실은 뜨는데 직원이 안 보임 | `office/status.json` 파일이 올라갔는지 확인 |
| Actions에 빨간 X가 잔뜩 | 파일이 엉뚱한 폴더에 들어감. `.github/workflows/post.yml` 위치 확인 |
| 초록 체크인데 글이 안 올라감 | 파일 이름 시간이 아직 안 됐거나, 3시간 넘게 지난 시간이라 건너뜀 → 이름의 시간 다시 쓰기 |
| 사진 글만 실패 | 저장소가 Private이거나, `images`에 그 이름의 사진이 없음 |
| 15분마다가 아니라 늦게 돎 | GitHub 무료 예약은 몇 분~수십 분 늦을 수 있어요. 정시에 돌리는 법은 📝 부록 |
| 갑자기 전부 실패 | 비밀번호를 바꿨거나 토큰 만료 → 3-1의 7번 다시 |
