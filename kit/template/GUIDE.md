# 🏢 나만의 AI 사무실 만들기

> 📸 표시는 화면 캡처가 들어갈 자리예요. (베타 전에 채움)
> 막히면 그 화면을 캡처해서 AI한테 "여기서 뭘 눌러야 해?"라고 물어봐도 대부분 해결돼요.

코딩 몰라도 돼요. 브라우저만 있으면 돼요.
순서는 이래요.

1. **사무실 띄우기** (15분, 가입 포함) → 귀여운 사무실이 내 주소에 생겨요
2. **직원 꾸미기** (10분) → 이름·대사·동물을 AI한테 말로 바꿔요
3. **직원에게 진짜 일 시키기** (30분) → 쓰레드를 연결하면 직원들이 실제로 일해요
4. **나만의 직원 뽑기** (선택) → 원하는 일을 하는 직원을 AI한테 추가해달라고 해요

1~2단계만 해도 사무실은 완성이에요. GitHub 계정이 없어도 처음부터 하나하나 알려줄게요.
3단계부터는 "보여주기용"이 아니라 진짜로 일하는 사무실이 돼요.

---

## 시작 전에: 낯선 말 5개

처음 보는 말이 나와도 겁먹지 마세요. 이것만 알면 돼요.

| 말 | 쉽게 말하면 |
|---|---|
| **GitHub (깃허브)** | 파일을 인터넷에 올려두는 무료 창고 사이트. 우리 사무실 건물이에요 |
| **저장소 (Repository)** | 창고 안의 내 방 하나. 사무실 파일이 전부 여기 들어가요 |
| **Commit (커밋)** | "저장" 버튼. 파일을 고치고 이걸 눌러야 반영돼요 |
| **Actions (액션)** | 정해진 시간마다 일하는 로봇. 내 컴퓨터가 꺼져 있어도 GitHub에서 대신 일해요 |
| **Secrets (시크릿)** | 금고. 비밀번호 같은 건 여기에만 넣어요. 넣으면 나도 다시 못 봐요 (그래서 안전해요) |

> 🖥️ **PC로 하는 걸 추천해요.** 폰으로도 되긴 하는데 메뉴가 숨어 있어서 헷갈려요.

## 1단계. 사무실 띄우기 (15분)

### 1-1. GitHub 가입하기 (5분)

이미 계정이 있으면 1-2로 넘어가요.

1. 브라우저에서 **github.com** 에 들어가요
2. 오른쪽 위 **Sign up** 버튼을 눌러요
   📸
3. 차례대로 입력해요
   - **Email**: 자주 쓰는 이메일
   - **Password**: 비밀번호 (15자 이상, 또는 8자 이상 + 숫자 + 소문자)
   - **Username**: 영어 아이디. ⚠️ **이게 사무실 주소가 돼요** (`아이디.github.io`). 실명 말고 별명으로 지어요
   - **Your Country/Region**: South Korea
   📸
4. **Continue** → "사람인지 확인" 퍼즐이 나오면 풀어요
5. 이메일로 온 **숫자 8자리**를 입력해요
   (메일이 안 보이면 스팸함 확인)
   📸
6. 로그인하고 나서 "어떤 일 하세요?" 같은 질문이 나오면 아무거나 고르거나 **Skip** 해도 돼요
7. 요금제를 물어보면 **Free (무료)** 예요. 돈 낼 일 없어요

### 1-2. 키트 복사해 오기 (2분)

1. 키트 링크를 눌러요 (신청 댓글에 답글로 받은 주소)
2. 초록색 **Use this template** 버튼 → **Create a new repository**
   📸 Use this template 버튼 위치
3. 이렇게 채워요
   - **Repository name**: 사무실 이름. 영어로 (예: `my-office`)
     ⚠️ 이것도 주소에 들어가요: `아이디.github.io/my-office`
   - **Public / Private**: **Public** 선택 ← 꼭!
     (쓰레드가 사진을 가져가려면 공개여야 해요. 비밀번호는 금고(Secrets)에 넣으니까 공개해도 안전해요)
   📸
4. 맨 아래 초록 버튼 **Create repository**
5. 파일 목록이 보이는 화면이 나오면 성공! 이게 내 사무실 저장소예요
   📸 완성된 저장소 화면

> 💡 이 화면 주소를 즐겨찾기 해두세요. 앞으로 자주 와요.

### 1-3. 사무실 문 열기 (5분)

사무실을 인터넷 주소로 볼 수 있게 켜는 단계예요.

1. 내 저장소 화면 위쪽 메뉴에서 **⚙️ Settings** 를 눌러요
   (메뉴가 안 보이면 **…** 를 누르면 숨어 있어요)
   📸 Settings 위치
2. 왼쪽 메뉴를 내려서 **Code and automation** 아래 **Pages** 를 눌러요
   📸
3. **Build and deployment** 에서
   - Source: **Deploy from a branch**
   - Branch: **main** 을 고르고, 옆 칸은 **/docs** 로 바꿔요
   - **Save**
   📸
4. 1~3분 기다려요. 같은 화면을 새로고침하면 위에 **"Your site is live at …"** 이 떠요
5. 그 주소 끝에 `office/` 를 붙여서 들어가요
   `https://아이디.github.io/my-office/office/`

직원 4명이 돌아다니는 사무실이 보이면 성공 🎉
직원을 눌러보고, 벽시계도 눌러보세요. (회식해요)

> 지금은 일이 없어서 다들 놀고 있어요. 3단계에서 일을 줄 거예요.

## 2단계. 직원 꾸미기 (10분)

코드를 직접 고칠 필요 없어요. **AI한테 파일을 주고 말로 시키면 돼요.**
ChatGPT, Claude, 제미나이 뭐든 돼요.

### 하는 법

1. 내 저장소 파일 목록에서 **docs** 폴더 → **office** 폴더 → **chars.js** 를 눌러요
2. 파일 내용 위쪽 오른편의 **복사 버튼**(📋 네모 두 개 겹친 모양)을 눌러요. 내용이 통째로 복사돼요
3. AI 채팅창(ChatGPT, Claude, 제미나이 등)에 붙여넣고, 아래 **복붙용 문장** 중 하나를 같이 보내요
4. AI가 새 파일 내용을 주면 그걸 통째로 복사해요
5. 다시 GitHub의 chars.js 화면 → 오른쪽 위 **연필(✏️) 버튼**
6. 안의 내용을 전부 지우고 (Ctrl+A → Delete) AI가 준 내용을 붙여넣어요
7. 오른쪽 위 초록 **Commit changes…** → 창이 뜨면 다시 **Commit changes**
8. 1~2분 뒤 사무실 주소를 새로고침하면 바뀌어 있어요

⚠️ AI가 "여기만 바꾸세요" 하고 일부만 주면, "파일 전체를 다시 보여줘"라고 한 번 더 말해요. 일부만 붙여넣으면 사무실이 안 떠요.

📸 파일 복사 버튼 / 연필 버튼 위치

### 복붙용 문장

**대사 바꾸기**
```
이 파일에서 토끼(reply) 직원 대사를 내 말투로 바꿔줘.
"댓글 왔다!!", "사장님 댓글 3개요!", "답장은 제가 할게요" 이런 느낌으로.
파일 전체를 다시 보여줘.
```

**동물 바꾸기**
```
이 파일에서 고양이(poster) 직원을 강아지로 바꾸고, 셔츠 색은 민트색으로 해줘.
파일에 있는 동물 중에서만 골라줘. 파일 전체를 다시 보여줘.
```

**직급·성격 바꾸기**
```
직원 4명(poster, reply, stats, key)에게 회사원 직급이랑 성격을 정해줘.
예: 고양이 대리는 완벽주의, 토끼 사원은 수다쟁이.
성격에 맞게 대사도 3개씩 바꿔서 파일 전체를 다시 보여줘.
```

> 💡 직원 이름표(게시 담당, 댓글 담당…)는 `office/status.py` 안에 있어요. 같은 방법으로
> "status.py에서 직원 이름을 '냥대리', '토끼사원'으로 바꿔줘"라고 시키면 돼요.

## 3단계. 직원에게 진짜 일 시키기 (30분)

이제 직원들이 진짜로 일해요.

| 직원 | 하는 일 | 언제 |
|---|---|---|
| 🐱 게시 담당 | 예약해둔 글·사진·영상을 쓰레드에 올려요 | 15분마다 |
| 🐰 댓글 담당 | 정해둔 단어가 들어간 댓글에 답글을 달아요 | 15분마다 |
| 🐹 통계 담당 | 팔로워 수가 바뀔 때마다 기록해요 | 15분마다 |
| 🐢 열쇠 담당 | 쓰레드 열쇠(토큰)를 새로 바꿔요 | 매달 1일·15일 |

글이 올라가는 동안엔 직원이 자리에 앉아 일하고,
끝나면 탕비실에서 커피 마시고,
문제가 생기면 울상이 돼요.
**전부 실제 기록 그대로예요.**

필요한 것: 쓰레드 계정, 페이스북 계정 (개발자 등록용, 쓰레드 계정과 달라도 돼요), PC

### 3-1. 쓰레드 열쇠(토큰) 받기

토큰은 "이 프로그램이 내 쓰레드에 글을 올려도 된다"는 열쇠예요.
🔒 **토큰은 아무 데도 붙여넣지 마세요. 채팅창·메모장·파일 전부 안 돼요. GitHub 비밀값 칸에만 넣어요.**

1. PC 브라우저에서 **developers.facebook.com** 에 들어가요
   - 페이스북에 로그인돼 있으면 그 계정으로 돼요. 없으면 페이스북 가입부터 해요
   - 이 페이스북 계정은 "앱 주인"일 뿐이에요. 글은 쓰레드 계정에 올라가니까 달라도 괜찮아요
   - 오른쪽 위 **시작하기**(Get Started) → 안내대로 개발자 등록 (휴대폰 번호·이메일 확인을 할 수 있어요)
   📸
2. 위쪽 **내 앱** → **앱 만들기**
   - 이용 사례: **"Threads API 액세스"** 하나만 체크
   - 비즈니스 연결: **안 함**
   - 앱 이름: 아무거나 (예: my-office)
   📸
3. **이용 사례 → 권한 및 기능** → 아래를 추가
   - threads_content_publish (글 올리기)
   - threads_manage_replies (답글 달기)
   - threads_read_replies (댓글 읽기)
   - threads_manage_insights (팔로워 수 보기)
   📸
4. **이용 사례 → 설정** → 콜백 URL 칸 3개에 내 블로그나 아무 내 사이트 주소 → 저장
   ⚠️ "OAuth 리디렉션 URI를 지정해주세요" 오류가 나면 → 주소를 다시 쓰고 **엔터**로 등록한 다음 저장
   📸
5. **앱 역할 → "Threads 테스터"** 탭 → 사람 추가 → 내 쓰레드 아이디 → "대기 중"이 보이면 OK
   ⚠️ 그냥 "테스터" 탭 말고 **"Threads 테스터"** 탭이에요
   📸
6. 폰 쓰레드 앱 → **설정 → 계정 → 웹사이트 권한 → 초대** → 수락
   ⚠️ 수락하면 버튼이 "삭제"로 바뀌어요. 정상이에요! 다시 보내지 마세요
   ⚠️ 수락하고 나면 메타 화면에서 내 아이디가 사라져요. 이것도 정상이에요
   📸
7. **이용 사례 → 설정** 맨 아래 **사용자 토큰 생성기** → 내 아이디 옆 "토큰 생성" → "계속"
   → 나온 긴 글자가 토큰이에요. **바로 다음 단계로!**
   📸 (토큰 글자는 가림)

### 3-2. 열쇠를 사무실 금고에 넣기

1. 내 저장소 → 위쪽 **⚙️ Settings**
2. 왼쪽 메뉴 **Security** 아래 **Secrets and variables** → **Actions**
3. 초록 버튼 **New repository secret**
4. **Name**: `THREADS_TOKEN` (대문자 그대로, 띄어쓰기 없이)
   **Secret**: 방금 받은 토큰 붙여넣기
5. **Add secret**
6. 목록에 THREADS_TOKEN이 보이면 끝. 값은 다시 안 보여요. 정상이에요 (금고니까요)
📸

### 3-3. 첫 글 올려보기

1. 저장소 파일 목록 → **posts** → **queue** → 예시 파일을 눌러요
2. 오른쪽 위 **연필(✏️) 버튼**
3. 내용을 내 첫 글로 바꿔요
4. 맨 위 **파일 이름 칸**도 바꿔요. 파일 이름이 곧 **올라갈 시간**이에요
   - 형식: `연월일-시분_아무이름.txt`
   - 지금 바로 올려보려면 **지금보다 5분 전** 시간으로 써요
   - 예: 12월 1일 낮 12시 10분에 하고 있다면 → `20261201-1205_첫글.txt`
5. **Commit changes…** → **Commit changes**
6. 위쪽 메뉴 **▶ Actions** → 왼쪽 **예약 게시** → 오른쪽 **Run workflow** → 초록 **Run workflow**
   📸
7. 노란 동그라미가 돌다가 초록 체크(✓)가 되면 끝 (1분쯤)
8. 쓰레드에 글이 올라와 있고, 사무실에서 고양이가 자리에 앉아 있으면 성공 🎉

> 💡 이 다음부터는 Run workflow를 안 눌러도 돼요. 15분마다 로봇이 알아서 확인해서, 시간이 된 글을 올려요.
> 예약하려면 파일 이름을 미래 시간으로 쓰면 끝이에요.

### 글 파일 쓰는 법

```
사진: a.jpg, b.mp4
주제: 일상
여기부터 본문이에요.
---
--- 위 줄 아래는 이어 쓰기(내 글에 다는 댓글)로 올라가요.
```

- `사진:` 줄은 선택이에요. 사진·영상은 `images` 폴더에 올려요. 2장 이상이면 넘겨보기 글이 돼요
- `주제:` 줄도 선택이에요. 쓰레드 주제 태그예요
- 폰 사진은 위치 정보를 지운 복사본을 올려요 (PC: 사진 오른쪽 클릭 → 속성 → 자세히 → 속성 및 개인 정보 제거)

### 3-4. 댓글 답장 규칙 정하기 (선택)

`replies.json`을 열어서 "단어"와 "답글"을 바꿔요.
댓글에 그 단어가 있으면 답글 중 하나를 골라 달아요.
한 번에 최대 5개, 같은 댓글엔 한 번만 달아서 스팸처럼 안 보여요.

### 3-5. 열쇠 자동 교체 (추천)

토큰은 60일이 지나면 만료돼요. 이걸 해두면 거북이 고문이 알아서 바꿔요.

1. GitHub 내 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access: 이 저장소만
   - Permissions → **Secrets: Read and write**
   📸
2. 나온 값을 3-2처럼 저장. 이름은 `GH_SECRETS_PAT`
3. **Actions → 토큰 연장 → Run workflow** 로 한 번 시험

⚠️ 쓰레드·인스타 **비밀번호를 바꾸면 토큰이 무효**가 돼요. 그땐 3-1의 7번만 다시 해서 `THREADS_TOKEN`을 바꿔요.

### 3-6. 폰 알림 (선택)

1. 폰에 **ntfy** 앱 설치 → 구독 → 남들이 못 맞힐 이름 (예: myoffice-x7k2q9)
2. 그 이름을 비밀값 `NTFY_TOPIC`으로 저장
3. **Actions → 예약 게시 → Run workflow** → mode 칸에 `알림테스트` → 폰에 알림 오면 성공

## 4단계. 나만의 직원 뽑기 (선택)

사무실의 진짜 재미는 여기예요. **원하는 일을 하는 직원을 AI한테 뽑아달라고 하면 돼요.**

1. 저장소에서 `office/status.py`, `docs/office/chars.js`, `.github/workflows/post.yml` 세 파일을 복사
2. AI 채팅창에 붙여넣고 이렇게 말해요

```
이건 내 AI 사무실 파일이야. 새 직원을 한 명 뽑고 싶어.
- 하는 일: (예: 매일 아침 9시에 날씨를 확인해서 비 오면 쓰레드에 "우산 챙기세요" 글 올리기)
- 동물: (예: 펭귄)
- 직급: (예: 인턴)
필요한 파일을 새로 만들거나 고쳐서 전부 보여줘.
GitHub에 어떤 파일을 어디에 올리면 되는지도 순서대로 알려줘.
토큰 같은 비밀값은 파일에 쓰지 말고 GitHub Secrets에서 읽게 해줘.
```

3. AI가 알려주는 대로 파일을 올리면 새 직원이 출근해요 🐧

> 💡 막히면 Actions의 빨간 X를 눌러서 나온 오류 문장을 그대로 AI한테 보여주면 대부분 해결돼요.

---

## 자주 막히는 곳

| 증상 | 이렇게 해요 |
|---|---|
| Actions 탭에 "워크플로를 켤까요?" 같은 초록 버튼이 있음 | 눌러서 켜요 (Enable / I understand…) |
| 사무실 주소가 404 | Pages 설정 후 1~2분 기다리기. 폴더가 `/docs`인지 확인 |
| 사무실은 뜨는데 직원이 안 보임 | `office/status.json` 파일이 올라갔는지 확인 |
| Actions에 빨간 X가 잔뜩 | 파일이 엉뚱한 폴더에 들어감. `.github/workflows/post.yml` 위치 확인 |
| 초록 체크인데 글이 안 올라감 | 파일 이름 시간이 아직 안 됐거나, 3시간 넘게 지난 시간이라 건너뜀 → 이름의 시간 다시 쓰기 |
| 사진 글만 실패 | 저장소가 Private이거나, `images`에 그 이름의 사진이 없음 |
| 15분마다가 아니라 늦게 돎 | GitHub 무료 예약은 몇 분~수십 분 늦을 수 있어요. 정시에 돌리는 법은 📝 부록 |
| 갑자기 전부 실패 | 비밀번호를 바꿨거나 토큰 만료 → 3-1의 7번 다시 |
