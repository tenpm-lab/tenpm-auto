# 설치 안내서 (초안)

> 📸 표시는 화면 캡처가 들어갈 자리예요. (베타 전에 채움)
> 코딩은 몰라도 돼요. 브라우저만 있으면 되고, 처음 한 번 30분~1시간 걸려요.

## 준비물

- 쓰레드 계정 (글이 올라갈 계정)
- 페이스북 계정 (개발자 등록용. 쓰레드 계정과 달라도 괜찮아요)
- GitHub 계정 (무료)
- PC 브라우저

---

## 1단계. 쓰레드 열쇠(토큰) 받기

토큰은 "이 프로그램이 내 쓰레드에 글을 올려도 된다"는 열쇠예요.
**토큰은 절대 아무 데도 붙여넣지 마세요. GitHub 비밀값 칸에만 넣어요.**

1. developers.facebook.com 에 들어가서 개발자 등록을 해요.
   브라우저에 로그인된 페이스북 계정으로 해도 돼요. 앱 주인일 뿐, 글이 올라가는 계정과는 상관없어요.
   📸 개발자 등록 화면
2. **앱 만들기** → 이용 사례는 **"Threads API 액세스"** 하나만 체크 → 비즈니스 연결은 **안 함** → 앱 이름은 아무거나 (예: my-threads-auto)
   📸 이용 사례 선택 화면
3. **이용 사례 → 권한 및 기능**에서 아래 권한을 추가해요.
   - threads_basic (기본으로 있음)
   - threads_content_publish (글 올리기)
   - threads_manage_replies (답글 달기)
   - threads_read_replies (댓글 읽기)
   - threads_manage_insights (팔로워 수 보기)
   📸 권한 추가 화면
4. **이용 사례 → 설정**의 리디렉션·제거·삭제 콜백 URL 칸에 내 블로그나 아무 내 사이트 주소를 넣고 저장해요.
   ⚠️ "OAuth 리디렉션 URI를 지정해주세요" 오류가 나면: 주소를 다시 입력하고 **엔터**를 눌러 등록한 다음 저장
   📸 콜백 URL 화면
5. **앱 역할 → "Threads 테스터"** 탭에서 사람 추가 → 내 쓰레드 아이디 입력 → "대기 중"이 보이면 OK
   ⚠️ 그냥 "테스터" 탭이 아니라 **"Threads 테스터"** 탭이에요
   📸 Threads 테스터 탭
6. 쓰레드 앱 → **설정 → 계정 → 웹사이트 권한 → 초대** → 수락
   ⚠️ 수락하면 버튼이 "삭제"로 바뀌어요. 수락 안 된 게 아니라 정상이에요. 다시 보내지 마세요
   ⚠️ 수락 뒤 메타 앱 역할 목록에서 내 아이디가 사라져도 정상이에요
   📸 쓰레드 웹사이트 권한 화면
7. **이용 사례 → 설정** 맨 아래 **사용자 토큰 생성기**에서 내 쓰레드 아이디 옆 "토큰 생성" → 동의 화면에서 "내아이디 계정으로 계속"
   → 나온 긴 글자가 토큰이에요. 바로 2단계로 가서 넣어요 (메모장에 저장해두지 마세요)
   📸 토큰 생성기 (토큰 글자는 가리고)

## 2단계. GitHub에 내 사무실 만들기

1. GitHub에서 **New repository** → 이름 아무거나 (예: my-office) → **Public** 선택
   ⚠️ 꼭 **Public**이어야 해요. 쓰레드가 사진을 가져가려면 공개 주소가 필요해요
   ⚠️ 공개 저장소라서, 토큰·비밀번호는 절대 파일에 쓰면 안 돼요 (비밀값 칸은 안전해요)
   📸 저장소 만들기 화면
2. 키트 파일을 올려요: **Add file → Upload files** → 키트 압축을 푼 폴더 안의 파일·폴더를 전부 끌어다 놓기 → Commit
   ⚠️ 복사해서 붙여넣기보다 **파일 업로드**가 안전해요 (붙여넣다가 내용이 빠지는 경우가 있었어요)
   ⚠️ `.github` 폴더가 숨김 폴더라 안 보일 수 있어요 → 📸 숨김 폴더 보이게 하는 법
3. **Settings → Secrets and variables → Actions → New repository secret**
   - 이름: `THREADS_TOKEN` / 값: 1단계에서 받은 토큰
   📸 비밀값 넣는 화면

---

## 3단계. 첫 글 올려보기

1. `posts/queue` 폴더의 예시 파일을 열어서 연필(수정) 버튼 → 내 글로 바꾸기
2. 파일 이름이 올라갈 시간이에요: `20261201-2030_story_첫글.txt` → 12월 1일 저녁 8시 30분
   지금 바로 올려보고 싶으면 이미 지난 시간(지금보다 10분 전)으로 적어요
3. **Actions → 예약 게시 → Run workflow** → 초록 체크가 뜨고 쓰레드에 글이 올라가면 성공 🎉
   📸 Run workflow 버튼

### 글 파일 쓰는 법

```
사진: a.jpg, b.jpg        ← (선택) images 폴더에 넣은 사진. 2장 이상이면 넘겨보기 글
주제: 일상                ← (선택) 쓰레드 주제 태그
여기부터 본문
---
--- 아래는 이어 쓰기(내 글에 다는 댓글)로 올라가요
```

- 사진은 `images` 폴더에 올려요 (영상 mp4도 돼요)
- 폰 사진은 위치 정보를 지운 복사본을 올리세요 (PC: 속성 → 자세히 → 속성 및 개인 정보 제거)

---

## 4단계. AI 사무실 열기

1. **Settings → Pages** → Source: Deploy from a branch → Branch: `main`, 폴더: `/docs` → Save
2. 1~2분 뒤 `https://내아이디.github.io/저장소이름/office/` 에 들어가면 사무실이 보여요
   📸 사무실 화면
3. 직원 대사는 `docs/office/chars.js`의 say 줄을 바꾸면 돼요

---

## 5단계. 댓글 자동 답장 (선택)

`replies.json`을 열어서 "단어"와 "답글"을 바꿔요.
댓글에 단어가 들어 있으면 답글 중 하나를 골라서 달아요. 한 번에 최대 5개, 같은 댓글엔 한 번만.

---

## 6단계. 열쇠 자동 연장 (선택이지만 강력 추천)

쓰레드 토큰은 60일이 지나면 만료돼요. 이걸 설정하면 매달 1일·15일에 자동으로 새 열쇠로 바꿔요.

1. GitHub → 내 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access: 이 저장소만
   - Permissions: **Secrets** → Read and write
   📸 PAT 만들기 화면
2. 나온 값을 2단계처럼 비밀값으로 저장: 이름 `GH_SECRETS_PAT`
3. **Actions → 토큰 연장 → Run workflow** 로 한 번 시험

⚠️ 쓰레드·인스타 **비밀번호를 바꾸면 토큰이 무효**가 돼요. 그때는 1단계 7번만 다시 해서 `THREADS_TOKEN`을 바꿔주세요.

---

## 7단계. 폰 알림 (선택)

글이 올라가거나 실패하면 폰으로 알림을 받을 수 있어요.

1. 폰에 **ntfy** 앱 설치 → 구독 → 남들이 못 맞힐 이름 정하기 (예: myoffice-x7k2q9)
2. 그 이름을 비밀값으로 저장: 이름 `NTFY_TOPIC`
3. **Actions → 예약 게시 → Run workflow** 에서 mode에 `알림테스트` 입력 → 폰에 알림 오면 성공

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| Actions에 빨간 X가 잔뜩 | 파일이 잘못된 폴더에 들어감. `.github/workflows/post.yml` 위치 확인 |
| 초록 체크인데 글이 안 올라감 | 파일 이름 시간이 아직 안 됨, 또는 3시간 넘게 지난 시간이라 건너뜀 (로그에 "밀린 글" 표시) |
| 사진 글만 실패 | 저장소가 Private이거나, images 폴더에 그 이름의 사진이 없음 |
| 15분마다가 아니라 늦게 돎 | GitHub 무료 예약은 몇 분~수십 분 늦을 수 있어요. 📝 정시에 돌리는 법은 부록 |
| 갑자기 다 실패 | 비밀번호를 바꿨거나 토큰 만료 → 1단계 7번 다시 |
